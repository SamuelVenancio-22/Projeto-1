<h1>🐾 We Care About Your Pet</h1>

<p>Um projeto desenvolvido com HTML e CSS para criar uma <br> página moderna e acolhedora dedicada ao cuidado dos animais de estimação.<p/>
<br>

<h2>📌 Sobre o projeto</h2>

<br>

<p>We Care About Your Pet é uma landing page criada para praticar e demonstrar conhecimentos em desenvolvimento web, utilizando HTML e CSS.

O projeto apresenta uma interface simples, moderna e responsiva, com foco em transmitir carinho e cuidado pelos pets. 🐶🐱</p>
<br>

   <ul>
      <li>HTML5</li>
      <li>CSS3</li> 
   </ul>
